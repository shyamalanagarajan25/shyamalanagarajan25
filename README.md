## Featured Project

### LIVEWIRE — Registration & Enquiry System

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github)](https://github.com/shyamalanagarajan25/Registeration-and-enquiry-system)

A Python desktop application developed using **Tkinter** for managing student registration and course enquiries through a structured two-step workflow.

**Key Features**

- Two-step Registration → Enquiry workflow
- Name and phone-number validation
- Required-field validation
- Course selection
- Warning, error, information and success dialogs
- Automatic transition between application windows
- Dark-themed graphical user interface
- Logo and QR-code image integration
- User details collected through multiple Tkinter widgets

**Technology Stack**

`Python` • `Tkinter` • `ttk` • `Pillow (PIL)`
